### 1.1 科学并不神秘

**课文正文**：

小时候，我们经常会问父母：天空为什么是蓝色的？冬天玻璃窗上为什么会出现冰花？小鸟为什么能在天上飞？这些问题看似简单，却蕴含着科学的奥秘。

科学就在我们身边。当秋天树叶变黄飘落，当雨后天空出现彩虹，当冬天雪花纷纷扬扬——这些都是自然现象。科学就是一门研究各种自然现象，并寻找它们产生、发展的原因和规律的学问。

科学研究从观察开始。牛顿看到苹果落地，从而发现了万有引力；瓦特观察到水壶盖被水蒸气顶起，最终改良了蒸汽机。这些伟大的发现都源于对日常现象的仔细观察和深入思考。其实，我们每个人都可以像科学家一样，用好奇的眼睛观察世界，用思考的头脑探索奥秘。

**什么是科学**：

**科学定义**：
科学是一门研究各种自然现象，并寻找它们产生、发展的原因和规律的学问。

**自然现象举例**：
- 自然界：闪电、彩虹、地震、火山喷发
- 生物界：种子发芽、蝴蝶蜕变、候鸟迁徙
- 日常生活：水沸腾、铁生锈、冰融化

**科学发现的故事**：

**牛顿与苹果**：
> 英国科学家牛顿在苹果树下看书时，一个苹果掉下来砸到了他的头上。他没有忽略这个常见的现象，而是思考：为什么苹果会往下掉，而不是往上飞？经过深入研究，他发现了万有引力定律。

**瓦特与蒸汽机**：
> 瓦特小时候看到水壶里的水烧开后，壶盖不停地跳动。他好奇地研究这个现象，最终改良了蒸汽机，推动了工业革命。

**科学就在我们身边**：
- 为什么天空是蓝色的？
- 为什么先看到闪电后听到雷声？
- 为什么夏天穿浅色衣服更凉快？
- 为什么煮熟的虾会变红？

### 1.2 走进科学实验室

**课文正文**：

进入中学，我们有了专门的科学实验室。实验室是我们进行科学探究的重要场所，里面摆放着各种仪器和设备。但是，实验室也存在一些潜在的危险，如果不遵守规则，可能会发生意外。因此，进入实验室的第一课，就是要了解实验室的安全规则和常用仪器的使用方法。

科学探究不是随意的猜测，而是有步骤、有方法的。一个完整的科学探究过程通常包括：提出问题、猜想与假设、制定计划、获取事实与证据、得出结论、检验与评价、表达与交流等环节。这就像侦探破案一样，需要一步步收集证据，最终找到真相。

**科学探究的基本过程**：

```
提出问题 → 猜想与假设 → 制定计划 → 获取事实与证据
                                            ↓
表达与交流 ← 检验与评价 ← 得出结论
```

**实验室安全**：

**实验室规则**：
1. 进入实验室要穿实验服，不能穿拖鞋
2. 不能携带食物和饮料进入实验室
3. 不能用手直接接触化学药品
4. 不能将鼻孔凑到容器口闻药品气味
5. 不能品尝任何药品
6. 实验完毕后要清洗仪器，整理桌面

**常见危险标志**：

| 标志 | 含义 |
|------|------|
| 🔥 | 易燃 |
| ☠️ | 有毒 |
| ⚡ | 触电危险 |
| 🧪 | 腐蚀 |
| ☢️ | 放射性 |

**常见实验仪器**：

**测量仪器**：
- **刻度尺**：测量长度
- **量筒**：测量液体体积
- **温度计**：测量温度
- **天平**：测量质量
- **秒表**：测量时间

**观察仪器**：
- **放大镜**：观察细小物体
- **显微镜**：观察微小结构
- **望远镜**：观察远处物体

**其他仪器**：
- **烧杯**：盛放液体，进行反应
- **试管**：少量试剂反应
- **酒精灯**：加热
- **漏斗**：过滤

### 1.3 科学观察

**课文正文**：

观察是科学研究的重要方法。许多科学发现都始于细致的观察。比如，青霉素的发现者弗莱明，就是在观察培养皿时，注意到青霉菌周围没有细菌生长，从而发现了青霉素。

观察不仅仅是"看一看"。科学的观察是有目的、有计划的，需要用多种感官参与，有时还要借助仪器。观察时，我们要如实记录，不能凭想象或主观意愿修改观察结果。观察之后，还要进行思考和交流，才能得出有价值的结论。

**阅读材料：列文虎克与显微镜**

17世纪，荷兰人列文虎克是一个眼镜店的学徒。他利用业余时间研磨镜片，制作出了能放大200多倍的显微镜。通过显微镜，他观察到了雨水中的微小生物、牙垢中的细菌，以及血液中的红细胞。这些发现开辟了微生物学的新领域。列文虎克的成功告诉我们：观察需要工具，更需要一颗永不满足的好奇心。

**观察的重要性**：

**观察的分类**：
- **直接观察**：用肉眼观察
- **间接观察**：借助仪器观察

**观察的要点**：
1. 要有明确的目的
2. 要全面、细致
3. 要实事求是
4. 要有记录
5. 要有思考和交流

**观察与实验**：

**例：观察蜗牛**：

**观察目的**：了解蜗牛的生活习性

**观察记录**：
| 观察项目 | 观察结果 |
|---------|---------|
| 外形 | 有壳，身体柔软 |
| 运动 | 缓慢爬行，留下黏液痕迹 |
| 触角 | 有两对触角，能伸缩 |
| 食物 | 喜欢吃菜叶 |
| 反应 | 触碰时缩回壳内 |

### 1.4 科学测量

**课文正文**：

在日常生活中，我们经常需要测量。妈妈做饭时要量米量水，爸爸装修时要量房量地，医生看病时要量体温量血压。测量就是把一个待测的量与公认的标准量进行比较的过程。

科学研究更是离不开测量。在科学实验中，我们需要测量长度、质量、体积、温度等各种物理量。测量的准确与否，直接影响实验结果的可靠性。那么，怎样才能做到准确测量呢？这就需要我们掌握正确的测量方法和仪器的使用技巧。

**阅读材料：秦始皇统一度量衡**

两千多年前，秦始皇统一中国后，颁布命令统一了全国的度量衡标准。他规定：一尺的长度、一升的量、一斤的重量，全国统一。这一举措大大促进了经济的发展和文化的交流。直到今天，我们仍然需要统一的计量标准，这就是国际单位制。

**测量的重要性**：

**测量误差**：
- 误差：测量值与真实值之间的差异
- 误差不可避免，但可以减小
- 减小误差的方法：多次测量取平均值

#### 长度的测量

**长度单位**：

**国际单位**：米（m）

**常用单位**：
| 单位 | 符号 | 换算关系 |
|------|------|---------|
| 千米 | km | 1 km = 1000 m |
| 米 | m | 基本单位 |
| 分米 | dm | 1 m = 10 dm |
| 厘米 | cm | 1 m = 100 cm |
| 毫米 | mm | 1 m = 1000 mm |
| 微米 | μm | 1 mm = 1000 μm |
| 纳米 | nm | 1 μm = 1000 nm |

**刻度尺的使用**：

**使用前**：
1. 观察零刻度线是否磨损
2. 观察量程（测量范围）
3. 观察分度值（最小刻度）

**使用时**：
1. 刻度尺要放正，不能歪斜
2. 刻度线要紧贴被测物体
3. 读数时视线要与刻度尺垂直
4. 读数要估读到分度值的下一位

**例题**：

**例1**：用刻度尺测量一支铅笔的长度，刻度尺的分度值是1mm，读数为15.20cm。请问这支铅笔的实际长度范围是多少？

**解**：
读数15.20cm中：
- 准确值：15.2cm
- 估计值：0.00cm

实际长度范围：15.15cm ~ 15.25cm

#### 体积的测量

**体积单位**：

**固体体积单位**：立方米（m³）

**液体体积单位**：升（L）、毫升（mL）

**换算关系**：
- 1 m³ = 1000 dm³
- 1 dm³ = 1 L
- 1 L = 1000 mL
- 1 mL = 1 cm³

**规则固体体积**：
- 长方体：V = 长 × 宽 × 高
- 圆柱体：V = πr²h

**液体体积测量**：

**量筒的使用**：
1. 选择合适量程的量筒
2. 将量筒放在水平桌面上
3. 读数时视线要与凹液面最低处平齐

**例题**：

**例2**：用量筒测量水的体积，读数时俯视读数为50mL，实际体积是多少？

**解**：
俯视读数偏大，实际体积小于50mL。
（仰视读数偏小，俯视读数偏大）

#### 温度的测量

**温度单位**：

**摄氏度（℃）**：
- 0℃：冰水混合物的温度
- 100℃：标准大气压下沸水的温度

**温度计的使用**：

**常用温度计**：
- 实验室温度计
- 体温计
- 寒暑表

**温度计的使用方法**：
1. 观察量程和分度值
2. 玻璃泡要全部浸入被测液体中
3. 不能接触容器底或容器壁
4. 待示数稳定后再读数
5. 读数时玻璃泡要继续留在液体中
6. 视线与液柱上表面平齐

**体温计的特殊构造**：
- 量程：35℃ ~ 42℃
- 分度值：0.1℃
- 玻璃泡上方有一段细弯管（缩口）
- 可以离开人体读数

**例题**：

**例3**：体温计的示数是37.5℃，没有甩就直接测量另一个人的体温，如果这个人的实际体温是36.8℃，体温计的示数会是多少？

**解**：
体温计有缩口，水银柱不会自动下降。
所以示数仍然是37.5℃。

### 1.5 科学探究

**课文正文**：

科学的核心是探究。科学家们通过不断提出问题、做出假设、设计实验、收集证据、分析数据，逐步揭开自然界的奥秘。作为中学生，我们也要学习科学探究的方法，培养探究的能力。

一次完整的科学探究，就像一次侦探破案。首先要发现"案情"——提出问题；然后根据已有线索做出推测——猜想与假设；接着制定调查方案——设计实验；再按方案收集证据——进行实验；最后分析证据得出结论——检验评价。如果结论不正确，还要重新假设、重新实验，直到找到真相。

**阅读材料：琴纳与牛痘疫苗**

18世纪末，英国医生琴纳观察到：挤牛奶的女工感染了牛痘后，就不会感染天花。他大胆猜想：接种牛痘也许可以预防天花。经过20多年的观察和实验，琴纳终于在1796年进行了第一次人体牛痘接种实验，并获得了成功。天花的预防使无数人免于死亡，琴纳的探究精神也激励着后人不断探索。

**科学探究的基本环节**：

**1. 提出问题**：
从日常生活、自然现象或实验观察中发现问题，并用明确的语言表述出来。

**2. 猜想与假设**：
根据已有知识和经验，对问题的可能答案作出猜想。

**3. 制定计划**：
设计实验方案，包括：
- 实验目的
- 实验器材
- 实验步骤
- 记录表格

**4. 获取事实与证据**：
按照计划进行实验，收集数据。

**5. 得出结论**：
分析数据，得出结论。

**6. 检验与评价**：
反思探究过程，评估结论的可靠性。

**7. 表达与交流**：
撰写报告，与他人分享。

**例题**：

### 2.1 生物与非生物

**课文正文**：

在我们周围，有各种各样的物体：桌子、椅子、石头、水，还有花草树木、鱼虫鸟兽。桌子不会自己长大，石头不会繁殖后代，但小草会发芽生长，小鸟会觅食育雏。那么，什么样的物体是生物，什么样的物体是非生物呢？

区分生物与非生物，不能只看外表，而要看它们是否具有生命的基本特征。生物能够进行新陈代谢，能够生长和发育，能够繁殖后代，能够对外界刺激作出反应，能够遗传和变异，还能适应和影响环境。这些特征，非生物都不具备。

**阅读材料：珊瑚是生物吗？**

美丽的珊瑚礁像海底的花园，但它们是由什么构成的呢？其实，珊瑚是由珊瑚虫的骨骼堆积而成的。珊瑚虫是一种微小的腔肠动物，属于生物。活着的珊瑚虫分泌石灰质骨骼，一代又一代堆积，就形成了珊瑚礁。所以，珊瑚虫是生物，而已经钙化的珊瑚骨骼则属于非生物。

**生物的基本特征**：

**1. 能进行新陈代谢**：
- 生物需要营养
- 生物能排出废物

**2. 能生长和发育**：
- 生物能由小长大
- 生物能繁殖后代

**3. 能对外界刺激作出反应**：
- 含羞草受到触碰会闭合
- 动物会躲避危险

**4. 能遗传和变异**：
- 子代与亲代相似（遗传）
- 子代与亲代有差异（变异）

**5. 能适应环境**：
- 仙人掌的叶变成刺
- 北极熊有厚厚的脂肪层

**6. 能影响环境**：
- 植物光合作用产生氧气
- 蚯蚓松土改良土壤

**生物与非生物的区别**：

| 特征 | 生物 | 非生物 |
|------|------|--------|
| 新陈代谢 | 有 | 无 |
| 生长 | 能 | 不能 |
| 繁殖 | 能 | 不能 |
| 应激性 | 有 | 无 |
| 遗传变异 | 有 | 无 |

### 2.2 细胞

**课文正文**：

我们都是由细胞构成的。一棵树、一只蚂蚁、一个人，虽然外形千差万别，但它们的基本结构单位都是细胞。细胞就像一个微型工厂，里面进行着各种生命活动。那么，细胞是怎么被发现的呢？它里面又有些什么呢？

1665年，英国科学家罗伯特·胡克用自制的显微镜观察软木塞的薄片，发现软木塞是由许多小室组成的，他把这些小室称为"细胞"。虽然胡克看到的只是植物死细胞的细胞壁，但这个发现为后来的细胞学研究奠定了基础。后来，科学家们不断改进显微镜，观察到了更多细胞的细节，逐步建立了细胞学说。

**阅读材料：施莱登、施旺与细胞学说**

19世纪，德国植物学家施莱登和动物学家施旺分别对植物和动物进行了大量观察，发现所有植物和动物都是由细胞构成的。他们共同提出了细胞学说：细胞是生物体结构和功能的基本单位。这一学说被认为是19世纪自然科学的三大发现之一，与进化论、能量守恒定律齐名。

### 2.3 生物体的结构层次

**课文正文**：

人体是由什么构成的呢？如果你回答"细胞"，那还不够完整。细胞就像砖块，砖块砌成墙，墙组成房间，房间构成楼房。同样，细胞先组成组织，组织构成器官，器官组成系统，系统再构成完整的生物体。这就是生物体的结构层次。

让我们以人体为例。皮肤表皮细胞排列在一起，形成上皮组织；肌肉细胞排列在一起，形成肌肉组织。这些不同的组织按照一定的次序组合起来，就形成了胃、心脏等器官。胃、肠等消化器官再组成消化系统。最后，消化系统、呼吸系统、循环系统等八大系统共同构成完整的人体。

**阅读材料：干细胞——生命的种子**

干细胞是一类具有自我复制和多向分化能力的细胞。它们就像生命的"种子"，在一定条件下可以分化成各种不同的细胞。科学家利用干细胞技术，已经成功培育出了皮肤、骨骼、血管等组织和器官。未来，干细胞技术有望用于治疗帕金森病、糖尿病等多种疾病，为医学带来革命性的突破。

**细胞 → 组织 → 器官 → 系统 → 个体**

**组织**：
由形态相似、结构和功能相同的细胞联合在一起形成的细胞群。

**植物组织**：
- 保护组织
- 营养组织
- 输导组织
- 分生组织

**动物组织**：
- 上皮组织
- 结缔组织
- 肌肉组织
- 神经组织

**器官**：
由不同的组织按照一定的次序结合在一起构成的具有一定功能的结构。

**植物器官**：
- 营养器官：根、茎、叶
- 生殖器官：花、果实、种子

**动物器官**：
- 心脏、肺、胃、肝等

**系统**：
能够共同完成一种或几种生理功能的多个器官按照一定的次序组合在一起。

**人体八大系统**：
1. 消化系统
2. 呼吸系统
3. 循环系统
4. 泌尿系统
5. 神经系统
6. 内分泌系统
7. 生殖系统
8. 运动系统

### 2.4 常见的动物

**课文正文**：

动物世界千姿百态，有在天空中翱翔的雄鹰，有在草原上奔跑的骏马，有在深海中游弋的鲸鱼，也有在泥土中蠕动的蚯蚓。面对如此繁多的动物，科学家们根据它们的特征进行了分类。

分类是认识事物的一种重要方法。我们可以根据动物体内有无脊椎骨，把它们分为脊椎动物和无脊椎动物两大类。脊椎动物包括鱼类、两栖类、爬行类、鸟类和哺乳类，它们的身体背部都有一条由脊椎骨组成的脊柱。无脊椎动物没有脊柱，种类更加繁多，占动物总数的95%以上。

**阅读材料：达尔文与进化论**

英国生物学家达尔文历时5年环球航行，观察了世界各地的动植物。他发现，不同岛屿上的地雀，喙的形状各不相同，这与它们的食物来源密切相关。据此，达尔文提出了自然选择学说，认为生物是在长期进化过程中逐渐形成的。进化论的提出，对生物学的发展产生了深远的影响。

**动物的分类**：

- 脊椎动物

| 两栖类 | 幼体水生，成体水陆两栖 | 青蛙、蟾蜍 |
| 爬行类 | 体表有鳞片或甲，卵生 | 蛇、龟、鳄鱼 |

### 2.5 常见的植物

**课文正文**：

从参天大树到微小苔藓，从鲜艳花朵到绿色藻类，植物世界同样丰富多彩。植物不仅美化了我们的环境，还为动物提供了食物和氧气。那么，这么多的植物又该如何分类呢？

根据繁殖方式的不同，植物可以分为孢子植物和种子植物两大类。孢子植物通过孢子繁殖，包括藻类植物、苔藓植物和蕨类植物。它们大多生活在阴湿的环境中，结构比较简单。种子植物通过种子繁殖，包括裸子植物和被子植物，它们更能适应陆地环境，是植物界最高等的类群。我们日常生活中见到的大多数植物，如水稻、小麦、苹果树等，都属于被子植物。

**阅读材料：银杏——活化石**

银杏是一种古老的裸子植物，距今已有2.7亿年的历史。在恐龙时代，银杏曾广泛分布于世界各地。后来，由于气候变化和冰川运动，银杏在许多地方灭绝了，但在中国却幸运地保存了下来，因此被称为"活化石"。银杏叶呈扇形，秋天变黄，非常美丽。它的种子（俗称白果）可以入药，但生食有毒，需要煮熟后才能食用。

### 3.1 地球的形状和内部结构

**课文正文**：

我们生活的地球是什么形状的？这个问题在今天看来很简单，但在古代却是一个难解之谜。古人抬头望天，看到"天似穹庐，笼盖四野"，大地平坦一望无际，于是认为"天圆地方"。但随着人们活动范围的扩大和科学技术的发展，人类对地球形状的认识逐渐深入。

公元前6世纪，古希腊数学家毕达哥拉斯最早提出了"地球是球形"的观点。他的学生亚里士多德在观察月食时发现，地球投射在月球上的影子是圆形的，从而进一步证实了地球是球体。1519年，葡萄牙航海家麦哲伦率领船队从西班牙出发，历时三年，完成了人类历史上第一次环球航行，用实践证明了地球是圆的。

现代科技让我们对地球有了更精确的认识。通过人造卫星拍摄的照片，我们看到地球是一个两极稍扁、赤道略鼓的不规则球体。

- 表面积：约5.1亿平方千米

**阅读材料：地核的温度**

地核的温度高达5000℃以上，比太阳表面还要热！但由于地核被厚厚的地幔和地壳包裹着，热量很难传到地面。只有在火山喷发时，我们才能一窥地球内部的高温岩浆。科学家通过研究地震波的传播速度，推测出了地球内部各层的温度和物质状态。

**地球的内部结构**：

**地壳**：
- 厚度：大陆地壳较厚（30-50千米），大洋地壳较薄（5-10千米）
- 组成：岩石

**地幔**：
- 厚度：约2900千米
- 组成：岩石（高温高压下呈塑性状态）

**地核**：
- 外核：液态
- 内核：固态
- 主要组成：铁、镍

### 3.2 地球仪和地图

**课文正文**：

地球这么大，我们不可能把它搬到课堂上来研究。于是，人们制作了地球的模型——地球仪。地球仪上画着经纬线，标注着国家和城市，让我们能够直观地了解地球表面的各种地理事物。

在地球仪上，与赤道平行的圆圈叫纬线，连接南北两极的半圆叫经线。纬线指示东西方向，长度不相等；经线指示南北方向，长度都相等。利用经纬线，我们可以确定地球表面任何一点的精确位置。

除了地球仪，地图也是我们认识世界的重要工具。一幅完整的地图必须包含三个要素：比例尺、方向和图例。比例尺告诉我们地图上的距离与实际距离的关系；方向帮助我们确定地理事物的方位；图例则解释了地图上各种符号的含义。

**阅读材料：地图的历史**

地图的历史可以追溯到四千多年前。古埃及人绘制了尼罗河流域的地图，古希腊人绘制了世界地图。中国最早的地图可以追溯到战国时期的《兆域图》。1973年，考古工作者在长沙马王堆汉墓中发现了三幅绘制在帛上的地图，分别是地形图、驻军图和城邑图，这是世界上现存最早的以实测为基础绘制的地图。

**地球仪**：

**经线和纬线**：

**纬线**：
- 与赤道平行的圆圈
- 指示东西方向
- 长度不等（赤道最长，两极最短）
- 纬度：赤道为0°，向两极各分90°

**经线**：
- 连接南北两极的半圆
- 指示南北方向
- 长度相等
- 经度：本初子午线为0°，向东向西各分180°

**重要的经纬线**：

| 名称 | 度数 | 意义 |
|------|------|------|
| 赤道 | 0°纬线 | 南北半球分界线 |
| 北回归线 | 23.5°N | 太阳直射的最北界线 |
| 南回归线 | 23.5°S | 太阳直射的最南界线 |
| 北极圈 | 66.5°N | 北半球极昼极夜的最南界线 |
| 南极圈 | 66.5°S | 南半球极昼极夜的最北界线 |
| 本初子午线 | 0°经线 | 东西经度起点 |
| 国际日期变更线 | 180°经线 | 日期变更线 |

**半球划分**：
- 南北半球：以赤道为界
- 东西半球：以20°W和160°E组成的经线圈为界

**地图**：

**地图三要素**：
1. **比例尺**：图上距离与实际距离之比
2. **方向**：一般定向法、指向标定向法、经纬网定向法
3. **图例和注记**

**比例尺**：
- 数字式：1:100000
- 线段式：0______10千米
- 文字式：图上1厘米代表实地1千米

**方向判断**：
- 一般定向法：上北下南，左西右东
- 指向标定向法：指向标箭头指向北方
- 经纬网定向法：经线指南北，纬线指东西

### 3.3 地球的运动

**课文正文**：

我们每天都会看到太阳从东方升起，西方落下，经历白天与黑夜的交替，感受春夏秋冬的轮回。这些常见的自然现象，都是由地球的运动造成的。

地球有两种基本运动方式：自转和公转。地球绕着地轴不停地旋转，叫做自转。自转一周大约需要24小时，也就是一天。正是由于地球的自转，我们才会看到昼夜交替和日月星辰的东升西落。

与此同时，地球还绕着太阳转动，叫做公转。公转一周大约需要365天，也就是一年。地球公转时，地轴是倾斜的，而且倾斜的方向保持不变。这一特点使得地球在公转过程中，太阳直射点在南北回归线之间来回移动，从而产生了四季变化和昼夜长短的变化。

**阅读材料：二十四节气**

二十四节气是中国古代劳动人民根据太阳在黄道上的位置变化而制定的，用来指导农事活动。早在春秋战国时期，我国就产生了仲春、仲夏、仲秋、仲冬四个节气。到了秦汉年间，二十四节气已经完全确立。2016年，二十四节气被列入联合国教科文组织人类非物质文化遗产代表作名录。

**地球的自转**：

**自转特征**：
- 绕转中心：地轴
- 方向：自西向东
- 周期：约24小时（一天）
- 产生的现象：
  1. 昼夜交替
  2. 日月星辰的东升西落
  3. 时间差异（东边比西边早）

**昼夜交替**：
- 地球是不透明的球体
- 太阳光只能照亮地球的一半
- 被照亮的是昼半球，未被照亮的是夜半球
- 随着地球自转，昼夜不断交替

**地球的公转**：

**公转特征**：
- 绕转中心：太阳
- 方向：自西向东
- 周期：约365天（一年）
- 轨道：椭圆形
- 产生的现象：
  1. 四季变化
  2. 昼夜长短变化
  3. 正午太阳高度变化
  4. 五带划分

**四季形成**：
- 地轴倾斜（约66.5°）且方向不变
- 太阳直射点在南北回归线之间移动
- 不同季节，同一地点获得的太阳热量不同

**五带划分**：

| 温度带 | 范围 | 特征 |
|--------|------|------|
| 热带 | 23.5°N ~ 23.5°S | 有太阳直射，终年炎热 |
| 北温带 | 23.5°N ~ 66.5°N | 四季分明 |
| 南温带 | 23.5°S ~ 66.5°S | 四季分明 |
| 北寒带 | 66.5°N ~ 90°N | 有极昼极夜，终年寒冷 |
| 南寒带 | 66.5°S ~ 90°S | 有极昼极夜，终年寒冷 |

### 4.1 物质的构成

**课文正文**：

世间万物都是由什么构成的呢？古人认为万物是由金、木、水、火、土五种元素组成的。随着科学的发展，人们认识到，物质是由极其微小的粒子构成的。这些粒子叫做分子。分子虽然小得肉眼看不见，但它们是真实存在的。

一滴水里大约有15万亿亿个水分子，这个数字大到难以想象！如果把水分子放大到乒乓球那么大，那么一个乒乓球就要放大到地球那么大。分子不仅很小，而且处于永不停息的运动之中。打开一瓶香水，很快整个房间都能闻到香味，这就是香水分子在空气中不断运动的结果。分子之间还存在间隙，因此水和酒精混合后，总体积会变小。

**阅读材料：阿伏伽德罗与分子论**

19世纪初，意大利科学家阿伏伽德罗提出了分子学说，认为物质是由分子组成的，分子是保持物质化学性质的最小粒子。阿伏伽德罗的学说在当时并没有引起足够的重视，直到1860年，在卡尔斯鲁厄国际化学会议上，他的学说才被广泛接受。为了纪念他的贡献，人们把1摩尔物质所含的粒子数称为"阿伏伽德罗常数"。

**分子**：

**分子的基本性质**：
1. 分子很小（直径约10⁻¹⁰米）
2. 分子在不断运动
3. 分子之间有间隙
4. 分子间存在相互作用力

**扩散现象**：
- 不同物质的分子彼此进入对方的现象
- 说明分子在不停地做无规则运动
- 温度越高，扩散越快

**例题**：

**例1**：在房间里打开一瓶香水，很快整个房间都能闻到香味，这是为什么？

**解**：
这是因为香水分子在不停地做无规则运动，扩散到空气中，所以整个房间都能闻到香味。

### 4.2 质量的测量

**课文正文**：

我们到超市买东西，常说"称一下有多重"。其实，在日常生活中说的"重量"，在科学上更准确的表述是"质量"。质量是物体所含物质的多少。一块铁和一块木头，如果它们的质量相同，就意味着它们所含物质的量是一样的。

质量是物体的一种基本属性，它不会因为物体的形状改变、状态变化、位置移动或温度升降而改变。比如，一块冰融化成水，虽然形状和状态变了，但质量不变；把一本书从北京带到上海，位置变了，但质量仍然不变。

测量质量的常用工具是天平。使用天平时要遵循"左物右码"的原则，并且要用镊子夹取砝码，不能用手直接拿，以免手上的汗液腐蚀砝码，影响测量精度。

**阅读材料：千克的历史**

1791年，法国科学家把4℃时1立方分米水的质量规定为1千克，并制作了一个铂制的标准千克原器。1889年，国际计量大会批准了这个千克原器，把它保存在法国巴黎的国际计量局。2018年，国际计量大会重新定义了千克：1千克等于普朗克常数除以6.62607015×10⁻³⁴焦耳·秒时对应的质量。这意味着千克不再依赖于实物原器，而是基于自然界的基本常数。

**质量**：

**定义**：物体所含物质的多少。

**单位**：
- 国际单位：千克（kg）
- 常用单位：吨（t）、克（g）、毫克（mg）
- 换算：1t = 1000kg, 1kg = 1000g, 1g = 1000mg

**质量的特性**：
- 质量是物体的基本属性
- 不随物体的形状、状态、位置、温度的改变而改变

**天平的使用**：

**使用步骤**：
1. 将天平放在水平桌面上
2. 调节平衡螺母，使指针指在分度盘中央（或左右摆动幅度相等）
3. 左盘放物体，右盘放砝码
4. 加减砝码并移动游码，使天平平衡
5. 物体质量 = 砝码质量 + 游码读数

**注意事项**：
- 不能用手直接拿砝码
- 潮湿的物体和化学药品不能直接放在托盘上
- 加减砝码时要轻拿轻放

### 4.3 物质的密度

**课文正文**：

为什么同样大小的铁块和木块，铁块比木块重得多？为什么油会浮在水面上？这些现象都与物质的密度有关。

密度是物质的一种特性。不同的物质，密度一般不同。我们可以用密度来鉴别物质。例如，黄金的密度是19.3克/厘米³，而铜的密度只有8.9克/厘米³。如果一个"金项链"的密度明显小于黄金的密度，那它很可能是假的。

密度还与物质的状态有关。同种物质在不同状态下，密度可能不同。比如，水的密度是1.0克/厘米³，而冰的密度只有0.9克/厘米³。这就是为什么冰会浮在水面上。

**阅读材料：水的反常膨胀**

大多数物质都是热胀冷缩的，但水却很特别。当水的温度从0℃升高到4℃时，体积反而会缩小，密度增大。只有当温度超过4℃后，水才恢复正常的热胀冷缩性质。因此，4℃的水密度最大。这一特性对水生生物的生存至关重要：冬天湖面结冰时，冰浮在水面上，而湖底的水保持在4℃左右，鱼类等水生生物才得以存活。

**密度**：

**定义**：单位体积某种物质的质量。

**公式**：
ρ = m/V

其中：
- ρ（rho）：密度
- m：质量
- V：体积

**单位**：
- 国际单位：千克/米³（kg/m³）
- 常用单位：克/厘米³（g/cm³）
- 换算：1g/cm³ = 1000kg/m³

**密度的特性**：
- 密度是物质的一种特性
- 同种物质，密度相同
- 不同物质，密度一般不同
- 密度与质量、体积无关

**常见物质的密度**：

| 物质 | 密度（g/cm³） |
|------|--------------|
| 水 | 1.0 |
| 冰 | 0.9 |
| 酒精 | 0.8 |
| 铁 | 7.9 |
| 铜 | 8.9 |
| 铝 | 2.7 |
| 金 | 19.3 |
| 水银 | 13.6 |

**例题**：

**例2**：一块金属的质量是540g，体积是200cm³，这是什么金属？

**解**：
ρ = m/V = 540g/200cm³ = 2.7g/cm³

查密度表可知，这是铝。

**例3**：一个瓶子能装1kg水，它能装多少kg酒精？（ρ酒精 = 0.8g/cm³）

**解**：
瓶子的容积：
V = m水/ρ水 = 1000g/1g/cm³ = 1000cm³

酒精的质量：
m酒精 = ρ酒精 × V = 0.8g/cm³ × 1000cm³ = 800g = 0.8kg

答：能装0.8kg酒精。

### 4.4 物质的比热

**课文正文**：

夏天，当我们赤脚走在沙滩上时，会感觉沙子烫脚，而海水却很凉爽。同样在阳光下照射，为什么沙子和水的温度变化如此不同呢？

原来，不同的物质吸收相同的热量时，升高的温度是不同的。科学家用"比热容"来描述物质的这种特性。比热容大的物质，升高相同的温度需要吸收更多的热量；反之，比热容小的物质，吸收相同的热量，温度升得更高。

水的比热容很大，这意味着水吸收很多热量后，温度也不会升高太多。正是由于水的这一特性，沿海地区昼夜温差较小，而沙漠地区昼夜温差很大。同时，汽车发动机用水做冷却剂、冬天暖气用水做传热介质，都是利用了水的比热容大的特点。

**阅读材料：热岛效应**

城市里的气温往往比郊区高，这种现象叫做"热岛效应"。这是因为城市里大量使用水泥、柏油等材料，这些材料的比热容较小，在阳光下容易升温；而郊区的水体、植被较多，水的比热容大，升温较慢。此外，城市里的工厂、汽车等排放大量热量，也是造成热岛效应的原因之一。热岛效应会影响城市的空气质量和居民的健康，因此城市规划中需要增加绿地和水体面积。

**比热容**：

**定义**：单位质量的某种物质，温度升高（或降低）1℃所吸收（或放出）的热量。

**单位**：焦/(千克·℃) [J/(kg·℃)]

**水的比热容**：
4.2×10³ J/(kg·℃)

**比热容的意义**：
- 比热容是物质的一种特性
- 水的比热容较大，所以：
  - 沿海地区温差小
  - 用水做冷却剂
  - 冬天暖气用水做介质

**热量计算**：
Q = cmΔt

其中：
- Q：热量
- c：比热容
- m：质量
- Δt：温度变化量

**例题**：

**例4**：把2kg水从20℃加热到100℃，需要吸收多少热量？

**解**：
Q = cmΔt
  = 4.2×10³ J/(kg·℃) × 2kg × (100℃-20℃)
  = 4.2×10³ × 2 × 80
  = 6.72×10⁵ J

答：需要吸收6.72×10⁵ J的热量。

### 4.5 熔化与凝固

**课文正文**：

春天，冰雪消融；冬天，滴水成冰。这些都是物质状态变化的常见现象。物质从固态变成液态的过程叫做熔化，从液态变成固态的过程叫做凝固。

不同的物质，熔化的特点不同。我们把有固定熔点的物质叫做晶体，如冰、食盐、金属等；没有固定熔点的物质叫做非晶体，如玻璃、松香、沥青等。晶体熔化时，虽然不断吸热，但温度保持不变，这个不变的温度就是熔点。而非晶体熔化时，温度会持续升高。

同一种晶体的凝固点和熔点是相同的。比如，冰在0℃时熔化成水，水在0℃时凝固成冰。这一特性在生产和生活中有广泛应用，比如冬天在汽车水箱中加入防冻液，可以降低水的凝固点，防止水箱冻裂。

**阅读材料：合金的妙用**

纯金属虽然有很多优良性能，但往往存在一些缺点。比如，纯铁较软，纯金太软，都不适合做工具和首饰。如果把两种或多种金属（或金属与非金属）熔合在一起，就能得到具有更好性能的合金。焊锡是锡和铅的合金，熔点比纯锡和纯铅都低，容易熔化，适合用来焊接电子元件。不锈钢是铁、铬、镍的合金，不易生锈，被广泛用于制造餐具、医疗器械等。

**熔化**：

**定义**：物质从固态变成液态的过程。

**熔点**：
- 晶体熔化时的温度
- 同种晶体的熔点相同
- 不同晶体的熔点不同

**凝固**：

**定义**：物质从液态变成固态的过程。

**凝固点**：
- 晶体凝固时的温度
- 同种晶体的凝固点与熔点相同

**晶体与非晶体**：

| 特征 | 晶体 | 非晶体 |
|------|------|--------|
| 外形 | 规则 | 不规则 |
| 熔化特点 | 有固定熔点 | 没有固定熔点 |
| 熔化过程 | 温度不变 | 温度持续上升 |
| 代表物质 | 冰、食盐、石英 | 玻璃、松香、沥青 |

**熔化图像**：

**晶体熔化图像**：
```
温度
  ↑
  |        ______
  |       /      熔化过程（固液共存）
  |______/
  |
  |  固态      液态
  +--------------------→ 时间
```

**例题**：

**例5**：把0℃的冰放入0℃的水中（周围气温也是0℃），冰会熔化吗？为什么？

**解**：
冰不会熔化。
因为冰熔化需要吸收热量，但周围温度都是0℃，没有温度差，无法发生热传递，所以冰不能吸收热量，不会熔化。

### 4.6 汽化与液化

**课文正文**：

湿衣服晾在阳台上，不久就会变干；锅里的水加热后会越来越少。这些现象都是水变成了水蒸气散失到空气中，科学上把物质从液态变成气态的过程叫做汽化。

汽化有两种方式：蒸发和沸腾。蒸发是在液体表面进行的缓慢汽化，它可以在任何温度下发生。晾衣服就是利用蒸发使水分散失。而沸腾是在液体表面和内部同时进行的剧烈汽化，只有在达到一定温度（沸点）时才会发生。水在标准大气压下的沸点是100℃。

与汽化相反，物质从气态变成液态的过程叫做液化。夏天，从冰箱里拿出的饮料瓶外壁会"出汗"，这就是空气中的水蒸气遇到冷的瓶子，温度降低，液化成小水珠附着在瓶子表面。

**阅读材料：高压锅的原理**

高压锅是厨房里常见的炊具，它的工作原理与气压和沸点的关系有关。液体的沸点与气压有关：气压越高，沸点越高。高压锅密封性好，锅内的水蒸气不能逸出，使锅内气压高于标准大气压，水的沸点升高到120℃左右。食物在高温下更容易煮熟，从而缩短烹饪时间，节省能源。

**汽化**：

**定义**：物质从液态变成气态的过程。

**两种方式**：

**1. 蒸发**：
- 在液体表面进行的缓慢汽化
- 在任何温度下都能发生
- 影响因素：
  - 温度越高，蒸发越快
  - 表面积越大，蒸发越快
  - 空气流动越快，蒸发越快

**2. 沸腾**：
- 在液体表面和内部同时进行的剧烈汽化
- 在一定温度下发生（沸点）
- 沸腾时温度不变

**液化**：

**定义**：物质从气态变成液态的过程。

**液化方法**：
1. 降低温度
2. 压缩体积

**例题**：

**例6**：夏天从冰箱里拿出一瓶饮料，瓶子外面很快出现水珠，这是为什么？

**解**：
这是因为空气中的水蒸气遇到冷的瓶子，温度降低，液化成小水珠附着在瓶子外面。

### 4.7 升华与凝华

**课文正文**：

冬天，放在衣柜里的樟脑丸会越来越小，最后消失不见；严寒的冬天，冰冻的衣服在室外也能慢慢变干。这些现象中，物质并没有经过液态，而是直接从固态变成了气态，这种物态变化叫做升华。

与升华相反，物质从气态直接变成固态的过程叫做凝华。深秋或初春的早晨，地面和植物上会出现一层白色的霜，这就是空气中的水蒸气在低温下直接凝华成固态的小冰晶。冬天窗户玻璃上出现的冰花，也是水蒸气凝华形成的。

升华和凝华在生产和生活中有很多应用。利用干冰（固态二氧化碳）升华时吸收大量热量，可以使周围温度迅速降低，因此干冰常用于人工降雨、食品冷藏和舞台烟雾效果。而凝华现象则提醒我们，在寒冷的季节要注意防寒保暖。

**阅读材料：人工降雨**

人工降雨是利用物理原理增加降水的一种技术。当云层中有足够的水蒸气但缺少凝结核时，可以向云层中播撒干冰或碘化银。干冰升华时吸收大量热量，使周围温度急剧下降，水蒸气凝华成小冰晶。碘化银则作为凝结核，使水蒸气在其表面凝华。这些小冰晶长大后下落，在下降过程中融化成水滴，就形成了降雨。

**升华**：

**定义**：物质从固态直接变成气态的过程。

**实例**：
- 樟脑丸变小
- 冬天冰冻的衣服变干
- 碘加热变成碘蒸气
- 干冰（固态二氧化碳）变成气体

**凝华**：

**定义**：物质从气态直接变成固态的过程。

**实例**：
- 霜的形成
- 冬天窗户上的冰花
- 雾凇的形成
- 碘蒸气遇冷变成碘晶体

**例题**：

**例7**：舞台表演时，经常喷洒干冰制造白雾效果，这是为什么？

**解**：
干冰是固态二氧化碳，在常温下会升华，吸收大量的热，使周围空气温度降低。空气中的水蒸气遇冷液化成小水珠，形成白雾。
