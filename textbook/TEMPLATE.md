# 教材 Markdown 采集模板规范

> 本文档定义了向知识库采集教材内容时的 Markdown 格式规范。
> 遵循本规范可确保系统自动分块、向量化和检索的准确性。

---

## 一、文件命名规范

```
{版本}{年份}{年级}{学期}{学科}_{内容类型}.md
```

| 字段 | 示例 | 说明 |
|------|------|------|
| 版本 | 部编版、人教版、浙教版、人教PEP版 | 教材出版版本 |
| 年份 | 2024、2025 | 教材版次年号 |
| 年级 | 七年级、八年级、九年级、高一、高二、高三 | 适用年级 |
| 学期 | 上册、下册 | 学期 |
| 学科 | 语文、数学、英语、科学、社会 | 学科名称（需与系统学科名一致） |
| 内容类型 | 完整教材内容、教材梳理知识库 | 文件内容类型 |

**示例：**
- `部编版2024七年级下册语文_完整教材内容.md`
- `浙教版2025八年级上册数学_完整教材内容.md`
- `人教版2024高一上册物理_完整教材内容.md`

---

## 二、文档整体结构

文档必须遵循以下标题层级：

```markdown
# {版本}{年份}{年级}{学期}{学科} — {内容类型}

## 教材整体结构
（教材概览表格，可选）

## {单元/章节标题}

### {课文/课时标题}

#### 子内容块
...

### {下一课时}
...

## {下一单元/章节}
...
```

**层级约定：**

| Markdown 层级 | 语义 | 系统行为 |
|--------------|------|---------|
| `#` | 文档标题 | 忽略，不分块 |
| `##` | 单元/章节 | 分块边界，提取为 `chapter` metadata |
| `###` | 课文/课时 | 分块边界，提取为 `lesson` metadata |
| `####` | 子内容 | 归入所属 `###` 块内，不分块 |

> **核心规则**：系统以 `###` 为最小分块粒度。每个 `###` 及其下属所有 `####` 内容会被打包为一个检索块。

## 三、各学科具体模板

### 3.1 语文

```markdown
# 部编版2024七年级下册语文 — 完整教材内容

## 教材整体结构
| 项目 | 内容 |
|------|------|
| 单元数 | 6个单元 |
| 教读课文 | ... |

---

## 第一单元：{单元主题}

**单元主题**：...
**语文要素**：...

---

### {课文名}

**作者简介**：...
**创作背景**：...

#### 课文全文

（课文原文完整粘贴此处，不要省略）

#### 重点字词注音

| 词语 | 注音 |
|------|------|
| ... | ... |

#### 课文结构
...

#### 主题思想
...

#### 课后习题
...

### {下一篇课文}
...

### 课外古诗词4首（一）

#### 《峨眉山月歌》/李白

**原文：**
...

**注释：**
...

**译文：**
...

**赏析：**
...

#### 《江南逢李龟年》/杜甫
...
```

**`###` 标题建议**：直接使用课文名（如 `春`、`济南的冬天`），或 `第X课 {课文名}`。系统通过子串匹配定位课文，核心名称必须出现在标题中。

**课外古诗词处理**：不要将"课外古诗词诵读"设为独立的 `##` 章节。应将其归入对应单元末尾，以 `### 课外古诗词4首（X）` 作为课时标题（如 `### 课外古诗词4首（一）` 放在第三单元后，`### 课外古诗词4首（二）` 放在第六单元后）。每首诗用 `#### 《诗名》/作者` 作为子标题，保持在一个 `###` 块内，系统会将其打包为一个整体检索块。

## 四、关键约束清单

### 4.1 必须遵守

- [ ] `##` 和 `###` 必须成对出现，每个 `###` 必须位于某个 `##` 之下
- [ ] `###` 标题中必须包含可识别的课时/课文名称（这是检索定位的关键）
- [ ] 同一教材内，`###` 标题不要重复（英语除外，英语需要加单元前缀）
- [ ] 课文全文必须完整粘贴，不要节选或省略

### 4.2 建议遵守

- [ ] 每个 `###` 块的内容控制在 5000 字以内。如果内容过长，用 `####` 拆分但保持在一个 `###` 下
- [ ] 使用标准的 Markdown 语法（`#` `##` `###` `####`），不要使用 HTML 标题标签
- [ ] 表格、列表使用标准 Markdown 格式
- [ ] 图片暂时用文本描述替代（如 `[图：细胞结构示意图]`），系统暂不支持图片检索

### 4.3 禁止

- [ ] 不要在 `###` 标题中使用与课时无关的修饰语作为唯一标识（如 `### 第一课时` 这种无法区分内容的标题）
- [ ] 不要将多篇课文合并到一个 `###` 下（课外古诗词4首等合集除外，见 3.1 节说明）
- [ ] 不要将"课外古诗词诵读"设为独立的 `##` 章节，应归入对应单元
- [ ] 不要在 `###` 和 `####` 之间插入额外的 `##` 或 `###`

## 五、系统如何处理这些文件

1. **扫描**：运行 `python backend/scripts/ingest_textbooks.py`
2. **解析文件名**：自动提取 `学科`、`年级`、`学期`、`版本`
3. **分块**：按 `##` → `###` 层级切分
4. **生成 Metadata**：每个块自动打上 `subject`、`grade`、`semester`、`chapter`、`lesson`、`content_type` 标签
5. **向量化**：调用 Embedding API 生成向量，存入 ChromaDB
6. **检索**：用户选择课文后，系统通过 `lesson` metadata 精确匹配原文块
