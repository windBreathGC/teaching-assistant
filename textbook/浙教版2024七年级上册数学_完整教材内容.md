### 1.1 从自然数到有理数

**知识回顾**：
- 自然数：0, 1, 2, 3, ...（用于计数和排序）
- 分数：如 1/2, 3/4（用于表示部分与整体的关系）

**新知引入**：

**情境导入**：
> 某仓库运进货物5吨记作+5吨，那么运出3吨应记作什么？
> 气温零上5℃记作+5℃，那么零下3℃应记作什么？

**概念形成**：

**正数与负数**：
- 正数：大于0的数，如 +5, +3.2, 1/2（"+"号可省略）
- 负数：小于0的数，如 -3, -2.5, -1/3（"-"号不可省略）
- 0：既不是正数，也不是负数

**相反意义的量**：
- 收入与支出
- 上升与下降
- 向东与向西
- 零上与零下

**例题解析**：

**例1**：填空
(1) 如果收入100元记作+100元，那么支出50元记作____元
(2) 如果水位上升2米记作+2米，那么下降1.5米记作____米
(3) 如果向东走30米记作+30米，那么向西走20米记作____米

**解**：
(1) -50
(2) -1.5
(3) -20

**例2**：某食品包装袋上标有"净含量：500±5克"，这是什么意思？

**解**：
"500±5克"表示净含量的标准值是500克，允许的误差范围是±5克。
- 最多：500 + 5 = 505克
- 最少：500 - 5 = 495克

**有理数的概念**：

整数和分数统称为有理数。

**有理数的分类**：

```
有理数
├── 整数
│   ├── 正整数（如1, 2, 3, ...）
│   ├── 零（0）
│   └── 负整数（如-1, -2, -3, ...）
└── 分数
    ├── 正分数（如1/2, 3.5, ...）
    └── 负分数（如-1/3, -2.7, ...）
```

### 1.2 数轴

**概念引入**：

**数轴的定义**：
规定了原点、正方向和单位长度的直线叫做数轴。

**数轴的三要素**：
1. **原点**：表示0的点
2. **正方向**：通常向右为正方向（用箭头表示）
3. **单位长度**：选取适当的长度为单位长度

**画数轴的步骤**：
1. 画一条水平直线
2. 在直线上取一点作为原点
3. 规定向右为正方向，用箭头表示
4. 选取适当长度为单位长度

**例题解析**：

**例1**：画出数轴，并在数轴上表示下列各数：
-3, 0, +2, -1.5, 2.5

```

     |    |     |     |    |
<----|----|-----|-----|----|---->
    -3   -2    -1     0    1    2    3
```

**例2**：指出数轴上A、B、C、D各点表示的数：
```
<----|----|-----|-----|----|---->
    -3   -2    -1     0    1    2    3
     A         B     C         D
```

**解**：
A表示-3，B表示-1，C表示0，D表示2

### 1.3 绝对值

**概念引入**：

**相反数**：
只有符号不同的两个数互为相反数。
- 5和-5互为相反数
- a和-a互为相反数
- 0的相反数是0

**绝对值的几何意义**：
一个数在数轴上对应的点到原点的距离叫做这个数的绝对值。

**绝对值的表示**：
|a| 表示数a的绝对值

**绝对值的性质**：
- 正数的绝对值是它本身：|5| = 5
- 负数的绝对值是它的相反数：|-3| = 3
- 0的绝对值是0：|0| = 0

**绝对值的代数定义**：
```
       { a,   当 a > 0 时
|a| =  { 0,   当 a = 0 时
       { -a,  当 a < 0 时
```

**例题解析**：

**例1**：求下列各数的绝对值：
-5, +3, 0, -2.5, 1/2

**解**：
|-5| = 5
|+3| = 3
|0| = 0
|-2.5| = 2.5
|1/2| = 1/2

**例2**：比较下列各组数的大小：
(1) -3 和 -5
(2) -2 和 0
(3) -1/2 和 -1/3

**解**：
(1) |-3| = 3, |-5| = 5
   因为 3 < 5，所以 -3 > -5

(2) 负数小于0，所以 -2 < 0

(3) |-1/2| = 1/2 = 3/6, |-1/3| = 1/3 = 2/6
   因为 3/6 > 2/6，所以 -1/2 < -1/3

**课内练习**：

1. 求下列各数的相反数和绝对值：
   -8, +5, 0, -3.5, 2/3

2. 化简：
   (1) |-(+3)|

   (3) |-(-2.5)|

3. 比较下列各组数的大小：

   (3) |-2.5| 和 |-3|

### 1.4 有理数的大小比较

**比较法则**：
1. 正数 > 0 > 负数
2. 两个正数比较，绝对值大的数大
3. 两个负数比较，绝对值大的反而小

**例题解析**：

**例1**：将下列各数按从小到大的顺序排列：
-3, +2, 0, -1.5, -2/3, 1

**解**：
先分类：
- 负数：-3, -1.5, -2/3
- 零：0
- 正数：+2, 1

负数比较绝对值：
|-3| = 3, |-1.5| = 1.5, |-2/3| ≈ 0.67
因为 3 > 1.5 > 0.67
所以 -3 < -1.5 < -2/3

正数比较：1 < 2

最终结果：-3 < -1.5 < -2/3 < 0 < 1 < +2

2. 将下列各数按从小到大的顺序排列，并用"<"连接：
   -4, +3, 0, -1.5, -5/2, +1, -(-2)

**作业题**：

A组：

2. 写出绝对值小于3的所有整数。

### 2.1 有理数的加法

**加法法则**：

**同号两数相加**：
取相同的符号，并把绝对值相加。
- (+3) + (+5) = +(3+5) = +8
- (-2) + (-4) = -(2+4) = -6

**异号两数相加**：
取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值。
- (+7) + (-3) = +(7-3) = +4
- (-5) + (+2) = -(5-2) = -3

**互为相反数的两数相加**：
和为0。
- (+4) + (-4) = 0

**一个数与0相加**：
仍得这个数。
- (-3) + 0 = -3

**加法运算律**：
- **交换律**：a + b = b + a
- **结合律**：(a + b) + c = a + (b + c)

**例题解析**：

**例1**：计算
(1) (-12) + (-8)
(2) (+15) + (-9)
(3) (-3.5) + (+3.5)
(4) 0 + (-7)

**解**：
(1) (-12) + (-8) = -(12+8) = -20
(2) (+15) + (-9) = +(15-9) = +6
(3) (-3.5) + (+3.5) = 0
(4) 0 + (-7) = -7

**例2**：用简便方法计算
(-2.8) + (+3.6) + (-1.2) + (-3.6)

**解**：
原式 = [(-2.8) + (-1.2)] + [(+3.6) + (-3.6)]
     = (-4) + 0
     = -4

**课内练习**：

1. 计算：

   (3) (+5) + (-7)
   (4) (-3.5) + (+3.5)

### 2.2 有理数的减法

**减法法则**：
减去一个数，等于加上这个数的相反数。

a - b = a + (-b)

**例题解析**：

**例1**：计算
(1) (+8) - (+5)
(2) (-6) - (-3)
(3) 0 - (-4)
(4) (-2.5) - (+1.5)

**解**：
(1) (+8) - (+5) = (+8) + (-5) = +3
(2) (-6) - (-3) = (-6) + (+3) = -3
(3) 0 - (-4) = 0 + (+4) = +4
(4) (-2.5) - (+1.5) = (-2.5) + (-1.5) = -4

**加减混合运算**：

**例2**：计算
(-20) + (+3) - (-5) - (+7)

**解**：
原式 = (-20) + (+3) + (+5) + (-7)
     = [(-20) + (-7)] + [(+3) + (+5)]
     = (-27) + (+8)
     = -19

### 2.3 有理数的乘法

**乘法法则**：

**两数相乘**：
1. 同号得正，异号得负
2. 把绝对值相乘

- (+3) × (+4) = +12
- (-2) × (-5) = +10
- (+6) × (-3) = -18
- (-4) × (+2) = -8

**任何数与0相乘**：
都得0。

**多个有理数相乘**：
- 负因数的个数为偶数时，积为正
- 负因数的个数为奇数时，积为负
- 有一个因数为0，积为0

**乘法运算律**：
- **交换律**：a × b = b × a
- **结合律**：(a × b) × c = a × (b × c)
- **分配律**：a × (b + c) = a × b + a × c

**例题解析**：

**例1**：计算
(1) (-4) × (-6)
(2) (+3) × (-8)
(3) (-2.5) × 0
(4) (-1) × (-2) × (-3) × (-4)

**解**：
(1) (-4) × (-6) = +(4×6) = +24
(2) (+3) × (-8) = -(3×8) = -24
(3) (-2.5) × 0 = 0
(4) (-1) × (-2) × (-3) × (-4)
    负因数有4个（偶数个），积为正
    = +(1×2×3×4) = +24

**例2**：用分配律计算
(-5) × (2/3 + 1/5 - 1/2)

**解**：
原式 = (-5) × (2/3) + (-5) × (1/5) - (-5) × (1/2)
     = -10/3 + (-1) - (-5/2)
     = -10/3 - 1 + 5/2
     = -20/6 - 6/6 + 15/6
     = -11/6

1. 计算：
   (1) (-4) × (+7)
   (2) (-6) × (-5)
   (3) (+2.5) × (-4)
   (4) (-3) × 0

### 2.4 有理数的除法

**倒数**：
乘积为1的两个数互为倒数。
- 3的倒数是1/3
- -2的倒数是-1/2
- 1/4的倒数是4
- 0没有倒数

**除法法则**：
除以一个数等于乘以这个数的倒数。

a ÷ b = a × (1/b) (b ≠ 0)

**两数相除**：
- 同号得正，异号得负
- 把绝对值相除
- 0除以任何不等于0的数都得0

**例题解析**：

**例1**：计算
(1) (-18) ÷ (+3)
(2) (-24) ÷ (-4)
(3) 0 ÷ (-5)
(4) (+3/4) ÷ (-2/3)

**解**：
(1) (-18) ÷ (+3) = -(18÷3) = -6
(2) (-24) ÷ (-4) = +(24÷4) = +6
(3) 0 ÷ (-5) = 0
(4) (+3/4) ÷ (-2/3) = (3/4) × (-3/2) = -9/8

### 2.5 有理数的乘方

**乘方的意义**：
求n个相同因数a的积的运算叫做乘方。

aⁿ = a × a × ... × a（n个a相乘）

**乘方的各部分名称**：
- aⁿ中，a叫做底数，n叫做指数，aⁿ叫做幂

**乘方的符号法则**：
- 正数的任何次幂都是正数
- 负数的奇次幂是负数，负数的偶次幂是正数
- 0的任何正整数次幂都是0

**例题解析**：

(3) (-1)⁴
(4) (-1)⁵

(2) (-3)² = (-3) × (-3) = +9
(3) (-1)⁴ = 1
(4) (-1)⁵ = -1

**例2**：计算

### 2.7 近似数

**准确数与近似数**：
- **准确数**：与实际完全符合的数，如班级有40名学生
- **近似数**：与实际接近的数，如人口约14亿、身高约1.75米

**精确度**：
- 一个近似数四舍五入到哪一位，就说这个近似数精确到哪一位
- 如3.14精确到百分位（0.01），3.140精确到千分位（0.001）

**有效数字**：
- 从左边第一个不是0的数字起，到末位数字止，所有的数字都叫做这个数的有效数字
- 如0.03020有4个有效数字：3, 0, 2, 0

**科学记数法与近似数**：
- 把一个数表示成 a×10ⁿ 的形式（其中1≤a＜10，n为整数）
- 例如：54770000 = 5.477×10⁷ ≈ 5.5×10⁷（保留两个有效数字）

**例题解析**：

(4) 1.804（精确到0.01）

**解**：
(1) 0.0158 ≈ 0.016
(2) 304.35 ≈ 304
(3) 1.804 ≈ 1.8
(4) 1.804 ≈ 1.80

**解**：

(2) 精确到万分位，有3个有效数字

**平方根的定义**：

**表示方法**：

- 读作"正负根号a"

**平方根的性质**：

- 0的平方根是0

(3) ∵ (±0.2)² = 0.04

### 4.3 整式

**单项式**：

**单项式的系数**：

**单项式的次数**：
一个单项式中，所有字母的指数的和叫做这个单项式的次数。

**多项式**：
几个单项式的和叫做多项式。

**多项式的项**：
多项式中的每个单项式叫做多项式的项。

**常数项**：
不含字母的项叫做常数项。

**多项式的次数**：
多项式里次数最高项的次数，叫做这个多项式的次数。

**整式**：
单项式和多项式统称为整式。

### 4.4 合并同类项

**同类项**：
所含字母相同，并且相同字母的指数也相同的项叫做同类项。
- 几个常数项也是同类项

**合并同类项**：
把多项式中的同类项合并成一项，叫做合并同类项。

**合并同类项法则**：
同类项的系数相加，所得的结果作为系数，字母和字母的指数不变。

**例题解析**：

**例1**：判断下列各组是不是同类项：
(1) 3x²y 与 -5x²y
(2) 2a³ 与 3a²
(3) -4 与 7

**解**：
(1) 是同类项（字母相同，相同字母的指数也相同）
(2) 不是同类项（a的指数不同）
(3) 是同类项（都是常数项）

**例2**：合并同类项
(1) 3x + 2x - 5x
(2) 2a²b - 3a²b + a²b
(3) 3x² - 2x + 5x² + 3x - 1

**解**：
(1) 3x + 2x - 5x = (3+2-5)x = 0

(2) 2a²b - 3a²b + a²b = (2-3+1)a²b = 0

(3) 3x² - 2x + 5x² + 3x - 1
   = (3x² + 5x²) + (-2x + 3x) - 1
   = 8x² + x - 1

### 4.5 整式的加减

**去括号法则**：
- 括号前是"+"号，去掉括号和"+"号，括号里各项的符号都不改变
- 括号前是"-"号，去掉括号和"-"号，括号里各项的符号都要改变

**添括号法则**：
- 添括号后，括号前是"+"号，括到括号里的各项都不变符号
- 添括号后，括号前是"-"号，括到括号里的各项都改变符号

**例题解析**：

**例1**：去括号
(1) +(a - 2b + 3c)
(2) -(2x - y + z)

**解**：
(1) +(a - 2b + 3c) = a - 2b + 3c
(2) -(2x - y + z) = -2x + y - z

**例2**：计算
(1) (3x² - 2x + 1) + (2x² + 3x - 5)
(2) (5a²b - 3ab²) - (2a²b - 4ab²)

**解**：
(1) 原式 = 3x² - 2x + 1 + 2x² + 3x - 5
         = (3x² + 2x²) + (-2x + 3x) + (1 - 5)
         = 5x² + x - 4

(2) 原式 = 5a²b - 3ab² - 2a²b + 4ab²
         = (5a²b - 2a²b) + (-3ab² + 4ab²)
         = 3a²b + ab²

**课内练习**：

### 5.2 等式的基本性质

**等式的性质1**：
等式两边都加上（或减去）同一个数或同一个整式，所得结果仍是等式。

如果 a = b，那么 a + c = b + c，a - c = b - c

**等式的性质2**：
等式两边都乘以（或除以）同一个数（除数不能为0），所得结果仍是等式。

如果 a = b，那么 ac = bc，a/c = b/c (c ≠ 0)

**例题解析**：

**例1**：利用等式的性质解方程
(1) x + 3 = 8
(2) 2x = 10

**解**：
(1) x + 3 = 8
   两边同时减去3：
   x + 3 - 3 = 8 - 3
   x = 5

(2) 2x = 10
   两边同时除以2：
   2x ÷ 2 = 10 ÷ 2
   x = 5

### 5.3 一元一次方程的解法

**解一元一次方程的一般步骤**：
1. **去分母**：方程两边同乘以各分母的最小公倍数
2. **去括号**：按去括号法则去掉括号
3. **移项**：把含未知数的项移到一边，常数项移到另一边
4. **合并同类项**
5. **系数化为1**：两边同除以未知数的系数

**例题解析**：

**例1**：解方程
3x - 2 = 2x + 5

**解**：
移项：3x - 2x = 5 + 2
合并同类项：x = 7

**例2**：解方程
2(x - 3) = 3(x + 1)

**解**：
去括号：2x - 6 = 3x + 3
移项：2x - 3x = 3 + 6
合并同类项：-x = 9
系数化为1：x = -9

**例3**：解方程
(x+1)/2 - (2x-1)/3 = 1

**解**：
去分母（两边同乘以6）：
3(x+1) - 2(2x-1) = 6
去括号：3x + 3 - 4x + 2 = 6
合并同类项：-x + 5 = 6
移项：-x = 1
系数化为1：x = -1

**例1**：某班有学生48人，其中男生比女生多4人，求男、女生各多少人？

**解**：
设女生有x人，则男生有(x+4)人。
根据题意：x + (x+4) = 48
解得：2x + 4 = 48
       2x = 44
       x = 22
男生：22 + 4 = 26（人）

答：女生22人，男生26人。

**行程问题**：

**例2**：甲、乙两地相距300千米，A车从甲地出发，速度为60千米/时，B车从乙地出发，速度为40千米/时。两车相向而行，几小时后相遇？

**解**：
设x小时后相遇。
根据题意：60x + 40x = 300
解得：100x = 300
       x = 3

答：3小时后相遇。

**工程问题**：

**例3**：一项工程，甲单独做需要10天完成，乙单独做需要15天完成。两人合作，几天可以完成？

**解**：
设两人合作x天完成。
甲每天完成1/10，乙每天完成1/15。
根据题意：(1/10 + 1/15)x = 1
解得：(3/30 + 2/30)x = 1
       (5/30)x = 1
       x = 6

答：两人合作6天可以完成。

**利润问题**：

**例4**：某商品按成本价提高40%后标价，再打8折出售，售价为224元。求成本价。

**解**：
设成本价为x元。
标价：x(1+40%) = 1.4x
售价：1.4x × 0.8 = 1.12x
根据题意：1.12x = 224
解得：x = 200

答：成本价为200元。

### 6.2 直线、射线、线段

**直线**：
- 向两方无限延伸
- 没有端点
- 表示方法：直线AB或直线l

**射线**：
- 向一方无限延伸
- 有一个端点
- 表示方法：射线OA

**线段**：
- 有两个端点
- 可以度量长度
- 表示方法：线段AB或线段a

**直线的性质**：
经过两点有且只有一条直线。（两点确定一条直线）

**线段的性质**：
两点之间，线段最短。

**两点间的距离**：
连接两点的线段的长度，叫做这两点间的距离。

**线段的中点**：
把一条线段分成两条相等线段的点，叫做这条线段的中点。

**例题解析**：

**例1**：已知线段AB=10cm，C是AB的中点，D是AC的中点，求AD的长。

**解**：
∵ C是AB的中点
∴ AC = 1/2 AB = 1/2 × 10 = 5cm

∵ D是AC的中点
∴ AD = 1/2 AC = 1/2 × 5 = 2.5cm

答：AD的长为2.5cm。

### 6.3 角

**角的概念**：
有公共端点的两条射线组成的图形叫做角。

**角的表示方法**：
- ∠AOB（用三个字母表示，顶点字母在中间）
- ∠O（用顶点字母表示，当只有一个角时）
- ∠1, ∠2（用数字表示）
- ∠α, ∠β（用希腊字母表示）

**角的度量**：
- 1° = 60′（1度等于60分）
- 1′ = 60″（1分等于60秒）

**角的分类**：
- 锐角：0° < α < 90°
- 直角：α = 90°
- 钝角：90° < α < 180°
- 平角：α = 180°
- 周角：α = 360°

**角的平分线**：
从一个角的顶点出发，把这个角分成两个相等的角的射线，叫做这个角的平分线。

**例题解析**：

**例1**：计算
(1) 35°28′ + 42°35′
(2) 90° - 36°42′

**解**：
(1) 35°28′ + 42°35′
   = (35° + 42°) + (28′ + 35′)
   = 77° + 63′
   = 77° + 1°3′
   = 78°3′

(2) 90° - 36°42′
   = 89°60′ - 36°42′
   = (89° - 36°) + (60′ - 42′)
   = 53° + 18′
   = 53°18′

**例2**：如图，已知∠AOB=80°，OC是∠AOB的平分线，求∠AOC的度数。

**解**：
∵ OC是∠AOB的平分线
∴ ∠AOC = 1/2 ∠AOB = 1/2 × 80° = 40°

### 6.4 余角和补角

**余角**：
如果两个角的和等于90°（直角），就说这两个角互为余角。
- ∠1 + ∠2 = 90°，则∠1是∠2的余角，∠2也是∠1的余角

**补角**：
如果两个角的和等于180°（平角），就说这两个角互为补角。
- ∠1 + ∠2 = 180°，则∠1是∠2的补角，∠2也是∠1的补角

**性质**：
- 同角（或等角）的余角相等
- 同角（或等角）的补角相等

**例题解析**：

**例1**：一个角的余角比这个角的补角的一半少15°，求这个角。

**解**：
设这个角为x°。
余角：(90 - x)°
补角：(180 - x)°

根据题意：90 - x = 1/2(180 - x) - 15
解得：90 - x = 90 - 1/2 x - 15
       90 - x = 75 - 1/2 x
       15 = 1/2 x
       x = 30

答：这个角为30°。

### 6.5 直线的相交

**对顶角**：
两条直线相交形成的四个角中，相对的两个角互为对顶角。
- 性质：对顶角相等
- ∠1与∠3是对顶角，∠2与∠4是对顶角

**邻补角**：
两条直线相交形成的四个角中，有公共顶点和一条公共边的两个角互为邻补角。
- 性质：邻补角互补（和为180°）

**垂线**：
两条直线相交成直角时，叫做互相垂直。
- 记作：AB⊥CD
- 交点叫做垂足

**垂线的性质**：
1. 过一点有且只有一条直线与已知直线垂直
2. 直线外一点与直线上各点连接的所有线段中，垂线段最短

**点到直线的距离**：
从直线外一点到这条直线的垂线段的长度，叫做点到直线的距离。

**例题解析**：

**例1**：如图，直线AB、CD相交于点O，∠AOC=50°，求∠AOD、∠BOD的度数。

**解**：
∵ ∠AOC与∠AOD互为邻补角
∴ ∠AOD = 180° - ∠AOC = 180° - 50° = 130°

∵ ∠BOD与∠AOC是对顶角
∴ ∠BOD = ∠AOC = 50°

**例2**：如图，直线AB、CD相交于点O，OE⊥AB，∠COE=55°，求∠BOD的度数。

**解**：
∵ OE⊥AB
∴ ∠AOE = 90°

∵ ∠AOC = ∠AOE - ∠COE = 90° - 55° = 35°

∵ ∠BOD与∠AOC是对顶角
∴ ∠BOD = ∠AOC = 35°

- 第7-14位：出生日期码（YYYYMMDD）

- 第18位：校验码

### 综合与实践二：图形的密铺

**活动目标**：
- 了解平面图形密铺的概念
- 探索哪些图形可以密铺
- 设计简单的密铺图案

**密铺的概念**：
用形状、大小完全相同的一种或几种平面图形进行拼接，彼此之间不留空隙、不重叠地铺成一片，这就是平面图形的密铺。

**活动任务**：
1. 用正三角形、正方形、正六边形进行密铺实验
2. 探索：正五边形能否单独密铺？为什么？
3. 用两种或多种正多边形组合进行密铺设计
4. 寻找生活中密铺的实例

**密铺的条件**：
- 在一个顶点处，各内角之和等于360°
- 例如：正三角形（60°）×6 = 360°；正方形（90°）×4 = 360°

## 阅读材料

### 阅读材料一：无理数的发现

公元前5世纪，古希腊毕达哥拉斯学派认为"万物皆数"，即一切量都可以用整数或整数之比（分数）来表示。学派成员希帕索斯在研究正方形的对角线时发现：若正方形边长为1，则对角线长为√2，而√2不能表示为两个整数之比。

这一发现动摇了毕达哥拉斯学派的基本信念。传说希帕索斯因此被同伴投入大海。但真理终究无法被淹没，无理数的存在被越来越多的人接受，成为数学发展史上的重要里程碑。

### 阅读材料二：方程史话

方程的历史可以追溯到古埃及和古巴比伦。古埃及的"莱茵德纸草书"（约公元前1650年）中记载了用"堆"（未知量）来解实际问题的方法。

中国古代数学名著《九章算术》（约公元前1世纪）中有"方程"章，专门讨论线性方程组的解法，其中使用的"筹算"方法与现代矩阵消元法原理相同。

阿拉伯数学家花拉子米（约公元780-850年）撰写了《还原与对消》一书，系统论述了一次和二次方程的解法，"代数"（algebra）一词即来源于此。

### 阅读材料三：几何学的起源

几何学起源于古埃及的测地术。尼罗河每年泛滥后，土地边界被冲刷，需要重新丈量，"几何"（geometry）一词在希腊文中就是"测地术"的意思。

公元前3世纪，古希腊数学家欧几里得撰写了《几何原本》，从少数几个公理出发，用严密的逻辑推理建立了完整的平面几何体系。这部著作是人类历史上最成功的教科书之一，其影响绵延两千多年。

**活动目的**：熟练进行有理数的混合运算。

**游戏规则**：
